Kazda Tag Language je hlavní nástroj pro psaní struktury webu pro framework: "Prumka Styl"

Pro stáhnutí spusťte:
```bash
npm install -g @ondra_honc/kztl
```

Pro stáhnutí rozčíření později:
```bash
kztl install-extension
```

nebo můžete vyhledat v extension marketplacu (KZTL: HTML Syntax and Snippets) / použít připravený .vsix
